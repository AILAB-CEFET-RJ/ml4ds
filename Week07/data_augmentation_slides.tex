\begin{frame}{What is Data Augmentation?}
  \begin{itemize}
    \item Strategy to synthetically expand the training distribution with plausible variations.
    \item Goal: improve generalization, robustness, and reduce overfitting without new labels.
    \item Should preserve the semantic label and reflect real-world variability.
    \item Costs: extra computation and possible slower convergence if too strong.
  \end{itemize}
\end{frame}

\begin{frame}{Augmentations for Images}
  \begin{itemize}
    \item Geometric: crop/pad, resize, flip, rotate, affine transform, perspective.
    \item Color/appearance: brightness/contrast/saturation/hue jitter, grayscale, blur, noise.
    \item Regularization: Cutout/RandomErasing, MixUp/CutMix (label mixing), elastic distortions.
    \item Normalization: dataset or ImageNet stats; no augmentation on val/test splits.
    \item Principles: start conservative, visualize samples, tune strength to domain.
  \end{itemize}
\end{frame}
